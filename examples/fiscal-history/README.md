# Fiscal history profile

This profile preserves the original application's period aliases, fiscal query
rewrites, and historical evidence guidance. It contains no source books.

Select it in your local `config.yaml` while retaining the other default settings:

```yaml
domain:
  profile: examples/fiscal-history/domain.yaml
```

Add documents you are permitted to use to `knowledge/docs/`, then index them
or upload them through the UI. Profile paths are relative to `config.yaml`.
