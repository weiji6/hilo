# Hilo 功能与发布核对记录

核对日期：2026-11-15。此记录区分源码保留、可复现测试与需要外部服务的验收。

## 仓库与历史

`weiji6/hilo` 是个人账号下的新独立公开仓库，基于经过筛选的源码快照建立，
没有导入原私有仓库的 Git 提交图。原仓库及其历史仍独立保留；本次修改不重写任一仓库的历史。
这不代表全部代码均为 Hilo 作者原创：DeerFlow 等上游的版权与 MIT 许可继续保留在 LICENSE、NOTICE。

## 对比结论

首次公开版与原工作副本比较：`backend/src` 中原有 155 个源码文件、
`frontend/src` 中原有 252 个文件均有对应文件；协议、后端服务与公共 Skills 文件也均保留。
这是文件覆盖核对，不是所有行为完全等价的证明。框架化还修改了领域配置、默认提示词、
产品文案、环境变量兼容、示例配置和启动方式。

首次发布存在配套工具遗漏和默认配置缩减，不能称为完整功能等价。本次补齐：

| 能力 | 修复与保留方式 |
| --- | --- |
| 结构化文档 SQLite 入库/FTS | 恢复 `scripts/ingest_structured_docs_to_db.py`，修正 `--docs-dir` 对默认 DB 路径的作用，支持缺失 DB 重建 |
| 知识库预热与向量重建 | 恢复 `scripts/prewarm_knowledge_indexes.py`、`scripts/reindex_global_knowledge.py` |
| 段落 ID 规范化 | 恢复 `scripts/normalize_structured_paragraph_ids.py` |
| PDF OCR 命令行 | 恢复 `backend/scripts/local_ocr.py`；需要用户部署兼容 MinerU gRPC 服务 |
| Kubernetes 沙箱组件 | 恢复 `docker/provisioner/app.py` 与镜像构建文件，另附通用配置文档 |
| 默认 Agent 工具 | 恢复 ls/read_file/bash/web_fetch/image_search 配置，Skills 可用 read_file 加载；研究子 Agent 仍受来源/工具范围约束 |
| Linux 本地命令执行 | 解除 `/bin/zsh` 硬依赖，按可用性回退到 bash、/bin/sh |
| Docker 辅助入口 | `scripts/docker.sh` 兼容模式检测并转到新的 Hilo Compose 命令，不使用原私有部署栈 |
| 源码导出 | 显式列入以上组件，回归测试检查实际导出目录中的运行源码与工具完整性 |

原部署专用 Compose/nginx、服务器同步/远程资料抓取、CI runner 安装、生产部署脚本、
私有数据修复和调试/性能采样脚本不随公开版发布。全量清空 Qdrant 再重建的旧维护脚本也未发布；
公开版提供面向配置知识库的重建入口。原录屏、示例会话和展示图片被排除。
这些不应被描述为已移植的部署/维护功能。新 Compose 是可移植的本地开发配置。

## 第二轮运行链路排查

继续排查发现并修复以下实际运行问题：

| 问题 | 修复与验证 |
| --- | --- |
| 快速开始示例可被目录搜索找到，但无上传记录时向量重建跳过它，正文定位也失败 | 全局索引与 locator 支持直接读取 UTF-8 Markdown/TXT；真实 Qdrant + 正文工具测试验证示例内容与引用 |
| Markdown/TXT 上传误调用未配置的 OCR 服务 | 线程、个人与全局上传改用本地文本解析，PDF/Office 保留外部解析路径 |
| 同名线程/个人文档可能读到全局 SQLite 正文 | scoped locator 不再查询全局段落库；回归验证来源正文隔离 |
| 独立进程先导入子 Agent 执行器时循环导入失败 | 延迟导出主 Agent 工厂；子进程实测首次导入 |
| Docker 与本地依赖清单漂移，包括缺少 Anthropic 集成 | 从 uv.lock 重新导出 requirements.txt，CI 比较两者 |
| Docker 两个后端未共享扩展配置，自定义 Skills 目录不可写 | 共享配置文件与可写 custom-skills 卷；检查 Compose 配置，并验证网关保存后另一进程可读 |
| 全局 PDF 页预览未使用 locator 解析出的实际文件名 | 文件名近似匹配后使用已解析文件；页预览路由回归验证 |

索引重建同时验证原始文本与结构化产物不重复入库、失败上传记录不会被原始文本回退绕过，
重复重建保持点数稳定。全局文本上传仍沿用先解析、再建立向量索引的工作流。

## 验证范围

本轮本地执行根目录 `make test`：**473 passed**。变更 Python 文件通过 Ruff，发布输入检查通过。
`make test` 现运行全部后端测试，CI 使用同一入口。前端 TypeScript 检查通过。

修复继承测试在收集阶段向全局 `sys.modules` 塞入依赖替身而产生的相互污染，
移除掩盖执行器循环导入的全局模拟，并更新已被框架化替换的历史领域提示词、
过时接口与缓存假设断言。这些测试调整与上表中的运行修复分别记录；通过测试不代表全部行为等价。

新增 `test_runtime_workflows.py` 使用虚构公开示例和临时目录，执行：

- 真实 FastAPI 网关的健康/模型接口、线程、个人及全局文本上传、解析和正文读取。
- 真实嵌入式 Qdrant 建库、写入及重复索引，验证个人集合与全局集合。
- 真实 LangGraph 主 Agent 与完整中间件链，同步及异步流式状态执行
  `book_search → knowledge_locate → 回答`，验证正文和引用登记进入最终状态。
- 网关保存 MCP 设置后独立进程读取配置，以及首次导入执行器。
- 个人文档同名替换、无效文本恢复、删除后向量清理，以及不存在的全局文档返回 404。

仅聊天与嵌入模型被确定性的本地替身替代；全局后台工作器在测试中同步执行以观察结果。
这些测试没有调用真实模型、远程 OCR 或外部 MCP 服务，也没有覆盖前端浏览器 SSE 传输。
流式状态测试不是逐 token 网络传输验收。运行仍有继承依赖弃用与 context 序列化警告。

上一轮的 SQLite/FTS、入库缺失 DB 重建、无 zsh 的 shell 回退、工具可用性、
源码导出、检索预算、正文证据、目录路由、引用和领域隔离回归继续执行。
前端静态演示缺失时的回退已在上一轮补齐；首次发布生产构建通过，当前轮无前端源码改动。

本轮认证 LangGraph 代理会把运行请求中的 `context` 和 `config.configurable` 的
`user_id`、`thread_id` 绑定到当前登录用户及已检查的 URL 线程；无归属线程的
`/runs/*` 请求被拒绝。临时 HTTP 模型替身实测了跨用户资料、线程附件、无依据回答
和模型服务失败后的下一次成功请求。该边界只适用于认证代理；后端直连接口仍按
`SECURITY.md` 说明视为本地部署接口。

## 独立整栈验收

2026-11-15 在全新 GitHub Ubuntu runner 上构建并启动 Hilo 公开源码，使用独立
Compose 项目、空 MariaDB/Qdrant 卷、虚构文档和本地 HTTP 模型测试服务。
[通过的整栈运行记录](https://github.com/weiji6/hilo/actions/runs/43719427612)。

实际通过以下流程：

- Python 与 Node Docker 镜像从源码构建，全部后端、前端、数据库与代理服务启动。
- 初始技术文档通过真实嵌入 HTTP 客户端写入独立 Qdrant（4 个向量块）。
- nginx 与 Next.js 入口可访问，认证代理拒绝匿名请求。
- MariaDB 迁移、账号注册、退出、重新登录和会话读取。
- 个人 TXT 上传、本地解析、后台索引完成及个人集合点数检查。
- 经认证代理创建 LangGraph 线程，上传线程 Markdown 并完成解析。
- 上传并安装自定义 Skill；另一个 Agent 容器进程能够读取该 Skill。
- 通过 nginx、Next.js 认证代理和 LangGraph 执行 SSE 请求，实际执行
  `book_search → knowledge_locate → 回答`；结果携带示例正文与引用，读取线程状态后引用仍在。
- 测试容器和数据卷自动清理。
- 在不删除数据卷的情况下重建容器后，账号、个人资料、Qdrant 向量、线程状态、引用登记
  和自定义 Skill 仍可读取；随后删除资料并确认文件与向量均清空。

这轮整栈运行进一步发现并修复两个启动错误：只读 Skills 根目录无法创建嵌套卷挂载点，
以及动态模块属性导出无法被 LangGraph 的模块字典发现。现在分别挂载只读 public Skills
和可写 custom Skills；工厂使用显式函数导出并在内部延迟导入。新增服务健康检查，入口等待
网关、LangGraph 与前端会话接口就绪后启动。

整栈测试运行真实应用、数据库、工具和网络传输；只有聊天和嵌入提供者使用确定性 HTTP
测试服务。它验证框架接线、数据与引用传递，不衡量模型理解、向量语义质量或回答质量，
也没有自动操作浏览器界面。生命周期验收只覆盖优雅容器重建，不代表断电或进程崩溃时的
写入耐久性。复现命令见 CONTRIBUTING.md。

服务器侧只建立过独立临时源码目录，基础镜像下载被该服务器的镜像代理超时阻断；
临时目录已清理，未修改生产部署。上述独立可运行结论来自干净 CI 的完整运行。
